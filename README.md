# 🎮 TwitchGames

Игры для стрима, которыми управляет чат, пока стримера нет на месте.

База: **реестр игр** (выбор/смена активной игры), **команды чата**, **OBS-оверлей**.
Первая игра для тестирования команд — **Змейка** 🐍.

📖 **Полная инструкция по настройке:** [SETUP.md](SETUP.md) — установка, Twitch-приложение, токены, `.env`, OBS, устранение неполадок.

## Структура

```
main.py               # точка входа: сборка бота
twitch_client.py      # подключение к чату Twitch (twitchio) + консольный эмулятор чата
core/
  base.py             # ChatEvent, CommandSpec, абстрактный класс Game
  registry.py         # GameRegistry: регистрация, выбор и смена активной игры
  global_commands.py  # глобальные команды: !games !game <id> !status !commands !help
  game_loop.py        # игровой цикл (tick активной игры ~2 раза в секунду)
games/
  snake.py            # Змейка — управляется командами чата
web/
  overlay_server.py   # HTTP-сервер: страница-оверлей для OBS + JSON-API состояния
requirements.txt
.env.example          # шаблон настроек для подключения к Twitch
```

## Быстрый старт (без Twitch — локальный тест)

```bash
pip install -r requirements.txt   # twitchio опционален для локального теста
python main.py
```

Без токенов в `.env` поднимается **сухой режим**: оверлей + эмулятор чата в консоли.
Вводите строки вида `viewer1: !game snake` — и получаете ответы бота.

Откройте в браузере (или добавьте как Browser Source в OBS):
`http://localhost:8080/overlay`

## Подключение к Twitch

1. Создайте приложение на https://dev.twitch.tv/console (OAuth Redirect URI: `http://localhost`).
2. Получите Client ID и токен бота (`oauth:...`) с доступом к чату канала.
3. `cp .env.example .env` и заполните значения.
4. `python main.py` — бот зайдёт в чат вашего канала.

## Команды чата

### Глобальные (работают всегда)

| Команда | Что делает |
|---|---|
| `!games` | список всех доступных игр |
| `!game <id>` / `!play <id>` / `!change <id>` | выбрать / **сменить** активную игру |
| `!status` | какая игра сейчас активна |
| `!commands` | команды активной игры |
| `!help` | общая справка |

### Змейка

| Команда | Что делает |
|---|---|
| `!start` | запустить / перезапустить партию |
| `!stop` | остановить игру |
| `!pause` / `!resume` | пауза / продолжить |
| `!up` `!down` `!left` `!right` | задать направление (алиасы: `вверх`, `влево`, `w/a/s/d`) |
| `!score` | счёт, рекорд и длина змейки |
| `!help` | команды игры |

Разворот на 180° игнорируется с подсказкой; рекорд сохраняется между партиями.

## Как добавить новую игру

1. Создайте `games/<имя>.py`, унаследуйте класс от `core.base.Game`.
2. Заполните `id`, `name`, `description`, `commands` и реализуйте
   `on_command()` + `get_state()` (при необходимости `tick()`).
3. Зарегистрируйте в `main.py`: `registry.register(MyGame)`.
4. Чат сразу сможет переключаться: `!game <имя>`.
