# Инструкция по настройке (упрощённая версия)

Никакой возни с консолью — всё в пару кликов. 🎮

## Коротко: 3 шага

1. **Установите Python** — скачайте с [python.org](https://www.python.org/downloads/), при установке **поставьте галочку «Add Python to PATH»** и жмите «Установить». Больше ничего делать не надо.
2. **Скачайте проект** — на GitHub нажмите зелёную кнопку **Code → Download ZIP**, распакуйте в любую папку.
3. **Запустите** — откройте папку и запустите файл:
   - **Windows:** двойной клик по `start.bat`
   - **Mac/Linux:** `./start.sh` (или через терминал)

Всё! Скрипт сам проверит и установит нужные библиотеки, а затем запустит бота. В окне появится надпись, что всё работает.

> При первом запуске Windows может спросить разрешение для Python — нажмите «Разрешить».

---

## Что происходит после запуска

- Бот уже играет в **Змейку** и ждёт команд чата.
- Без настроек Twitch он работает в тестовом режиме: можно вводить команды прямо в окно запуска, как будто пишет зритель, например: `viewer1: !start`
- Картинка игры доступна по адресу: **http://localhost:8080/overlay**

## Подключаем OBS (2 минуты)

1. В OBS добавьте источник **«Браузер»** (Browser).
2. URL: `http://localhost:8080/overlay`
3. Ширина `800`, высота `640`.
4. Готово — змейка на стриме. 🐍

## Подключаем настоящий чат Twitch (5 минут)

1. Зайдите на [dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps) → **«Регистрация приложения»**:
   - Name: любое, например `MyStreamGames`
   - OAuth Redirect URLs: `http://localhost`
   - Category: Application Integration
   - Client type: **Confidential**
2. Скопируйте **Client ID** и создайте **Client Secret**.
3. Получите токен бота на [twitchtokengenerator.com](https://twitchtokengenerator.com):
   - Authenticate with your **bot account**
   - Выберите scopes: `chat:read`, `chat:edit`
   - Скопируйте токен (строка вида `abc123...`, без слова `oauth:`)
4. В папке проекта создайте файл `.env` (рядом с `main.py`) и впишите:
   ```
   TWITCH_CLIENT_ID=ваш_client_id
   TWITCH_OAUTH_TOKEN=ваш_токен_без_oauth
   TWITCH_BOT_NAME=ник_бота
   TWITCH_CHANNEL=ваш_канал
   ```
5. Перезапустите `start.bat` — бот зайдёт в чат канала.

## Команды чата

| Команда | Что делает |
|---|---|
| `!games` | список всех игр |
| `!game snake` | выбрать/сменить игру (`snake` — змейка) |
| `!status` | состояние текущей игры |
| `!commands` | команды активной игры |
| `!start` / `!stop` | начать / остановить партию |
| `!pause` / `!resume` | пауза / продолжить |
| `!up` `!down` `!left` `!right` | направление (можно по-русски: `!влево`, и WASD) |
| `!score` | счёт и рекорд |

## Если что-то не так

- **Окно закрылось сразу** — значит нет Python. Установите с python.org, не забыв галочку «Add Python to PATH».
- **Пишет «Нет Twitch-креденшелов»** — это нормально, бот работает в тестовом режиме. Настройте `.env` (см. выше).
- **Бот не видит ваш чат** — проверьте, что в `.env` ник бота и канал написаны верно и ботFollow-ает канал.
- **Порт занят** — задайте другой: в `.env` строка `PORT=8090`, и в OBS тогда `http://localhost:8090/overlay`.

## Хочу добавить новую игру

Создайте файл `games/yourgame.py` по образцу `games/snake.py` (наследуете класс `Game`, описываете команды в `commands()` и логику в `tick()`), затем зарегистрируйте её в `main.py`:

```python
registry.register(YourGame)
```

Чат сразу подхватит новые команды — остальной код менять не нужно.
